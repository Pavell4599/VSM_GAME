# Игровое обучающее приложение для проводников ВСМ-400

Интерактивная геймифицированная виртуальная среда для подготовки проводников высокоскоростных магистралей к работе в условиях стресса, дефицита времени и нештатных ситуаций.

## 🚀 Архитектура и стек технологий
Проект реализован в виде модульного приложения с четким разделением ответственности (Цитата: Модульное приложение [1]):
* **Frontend:** Веб-интерфейс на Node.js / Vite (React/Vue) — личный кабинет проводника, симулятор диалогов, шкалы и таймеры.
* **Backend:** Сервер бизнес-логики на Python / Django — движок нелинейных сценариев, расчет баллов и логика компетенций.
* **Storage:** База данных SQLite для хранения профилей, логов активности, ачивок и структуры сценариев.

## 🛠️ Запуск проекта локально

### 1. Запуск Бэкенда (API)
```bash
cd Backend
python -m venv venv

# Для Windows (Powershell):
venv\Scripts\activate 

# Для macOS/Linux (Bash):
source venv/Scripts/activate 

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### 2. Запуск Фронтенда
В новом окне терминала выполните:
```bash
cd Frontend
npm install
npm run dev
```

* **Фронтенд:** http://localhost:8080
* **Бэкенд (API):** http://localhost:8000/admin

---

## 🐳 Запуск проекта через Docker
Убедитесь, что у вас установлен Docker и Docker Compose. В корневой директории проекта выполните:

```bash
docker-compose up --build
```

* **Фронтенд:** http://localhost:8080
* **Бэкенд (API):** http://localhost:8000/admin

## 📊 Демонстрационные данные и Сценарии
В соответствии с требованиями безопасности (152-ФЗ), в демо-среде используются исключительно **синтетические и анонимизированные данные**. В базу заложены типовые рабочие ситуации:
1. Конфликты между пассажирами в вагоне.
2. Медицинские инциденты на скорости 400 км/ч.
3. Сервисные кейсы премиального уровня обслуживания.

### Игровые механики, доступные в демо:
* **Нелинейный движок:** Сюжет зависит от ответов проводника.
* **Двойная шкала:** Одновременный расчет «Лояльности пассажира» и «Рейтинга безопасности».
* **Тайм-лимит:** Ограничение времени на критические решения.
* **Цикл геймификации:** Профиль -> Начисление очков -> Выдача ачивок -> Таблица лидеров.
