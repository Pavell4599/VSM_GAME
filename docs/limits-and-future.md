ОГРАНИЧЕНИЯ ТЕКУЩЕГО РЕШЕНИЯ:

1. ИИ-модель требует GPU для производительной работы
   - Мы арендовали российский сервер для запуска обученной нами модели
   - Если ИИ выходит из строя, в игре NPC отвечают по заранее заготовленным сценариям

2. Нет мультиплеера
   - Одиночное прохождение
   - План: совместные сценарии для всей бригады



ПЛАН РАЗВИТИЯ ПОСЛЕ ХАКАТОНА:

   - Синхронизация с табелем учёта рабочего времени

2. Расширенная аналитика 
   - Дашборд для руководителей с метриками по каждому проводнику

    - Добавление множества новых объектов, которые помогут точнее передать сложность реальных ситуаций и
      помогут бортпроводнику чувствовать себя в игре, как в реальной жизни, в реальном поезде, реально решая какой-то

    - Улучшение текстур
    - Добавление новых игровых механик:

        4)создание анимаций и визуализации для каждого сценария

4. Мобильное приложение
   - Тренировки в дороге - офлайн режим с множеством предустановленных сценариев
   - Push-уведомления о новых сценариях

5. Улучшение графики и плавности в игре
    - Улучшение плавности в игре
    - Обновление джойстика на более удобный


ИТОГ:

На данный момент у нас получился отличный стартовый прототип приложения

с анонимизированными никнеймами и защищенной базой данных. Очень красивая главная страница со списком лучших бортпроводников по очкам и уровню,
рабочими кнопками ИГРАТЬ и ПРОФИЛЬ. Страницей профиля, где игрок может посмотреть свой прогресс, посмотреть какие ачивки он уже получил, 
а какие еще нет(система ачивок тоже функциональна). Предигровой страницей, где игрок выбирает уровень сложности и длительность
игровой сессии. И самой страницей с игрой, полностью соответствующая критериям хакатона.
