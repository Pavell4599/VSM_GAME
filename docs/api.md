API проекта VSM_GAME представляет собой серверную часть приложения, реализованную на Python с использованием фреймворка Django. Именно на этом уровне сосредоточена вся ключевая бизнес-логика игрового обучающего комплекса, предназначенного для подготовки проводников высокоскоростных магистралей ВСМ-400. API выступает связующим звеном между пользовательским интерфейсом (веб-клиентом на Node.js / Vite) и базой данных, обеспечивая полный цикл взаимодействия игрока с системой — от старта сессии до получения итоговой оценки.

Одной из центральных функций API является динамическая генерация игрового контента. Система способна создавать различные сценарии, моделирующие реальные рабочие ситуации: конфликты между пассажирами, медицинские инциденты на скорости 400 км/ч, сервисные кейсы премиального уровня и другие нештатные обстоятельства. Помимо самих сценариев, API формирует и характеры пассажиров — их поведенческие модели, реакции и манеру общения. За счёт этого каждая игровая сессия может проходить по-разному, а игрок лишается возможности заучить единственно верную последовательность действий: сюжет развивается нелинейно и напрямую зависит от принятых решений.

Ключевой элемент логики — оценка рациональности действий игрока. По ходу прохождения API анализирует каждый выбор проводника, учитывая при этом сразу несколько параметров, включая «Лояльность пассажира» и «Рейтинг безопасности», а также соблюдение временных лимитов. На основании этого анализа система формирует итоговый результат работы игрока: насколько успешно он справился с задачей, какие ошибки были допущены, в каких моментах решение оказалось неоптимальным и, что особенно важно, как эти ошибки можно исправить. Таким образом, API выполняет не только оценочную, но и обучающую функцию — игрок получает обратную связь, которая помогает ему лучше понять правильную модель поведения.

Отдельного внимания заслуживает подсистема хранения данных. В базе данных (SQLite) хранятся профили игроков, их достижения, накопленный опыт, текущий уровень, логи активности и прочая статистика, связанная с игровым прогрессом. Это обеспечивает работу цикла геймификации: профиль → начисление очков → выдача ачивок → таблица лидеров. Благодаря этому пользователь видит свой прогресс, может сравнивать результаты с другими и возвращаться к обучению, отслеживая собственный рост.

Безопасность реализована на двух уровнях. Во-первых, доступ к игровым эндпоинтам защищён авторизационными токенами: без прохождения аутентификации получить доступ к функциональности нельзя. Во-вторых, соблюдаются требования 152-ФЗ «О персональных данных» — в демонстрационной среде используются исключительно синтетические и анонимизированные профили, а реальные персональные данные в базу не попадают. Такой подход позволяет безопасно демонстрировать систему, не нарушая законодательство.

В целом API проекта VSM_GAME — это полноценный серверный слой, который отвечает за генерацию контента, игровую логику, оценку действий, хранение прогресса и защиту данных. Он спроектирован модульно, с чётким разделением ответственности, что упрощает как разработку, так и дальнейшее масштабирование приложения.
