API обеспечивает генерацию игровых сценариев и моделей поведения пассажиров. На основе действий игрока система оценивает рациональность принятых решений и возвращает результат прохождения с анализом допущенных ошибок и рекомендациями по их устранению. База данных хранит профили игроков, достижения, опыт, уровень и связанную статистику. Доступ к игровым эндпоинтам защищён токенной авторизацией. Обработка персональных данных соответствует требованиям 152-ФЗ: в демонстрационной среде используются анонимизированные профили на уровне БД.
