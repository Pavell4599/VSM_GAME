ПОЛЬЗОВАТЕЛЬСКИЙ СЦЕНАРИЙ

1.ВХОД НА ГЛАВНОЕ МЕНЮ
   - Ознакомление с главным меню, с кнопками Играть и Профиль
   - Ознакомление с таблицей лидеров (топ лучших проводников по уровню и количеству опыта)

2. РЕГИСТРАЦИЯ/ВХОД
   - Проводник создаёт аккаунт (username/password)
   - Видит свой профиль: уровень, XP, очки, достижения

3. ВЫБОР СЦЕНАРИЯ
   - Нажимает "ИГРАТЬ"
   - Выбирает класс вагона:
     * СТАНДАРТ (открыт сразу)
     * КОМФОРТ (требуется ур. 15)
     * БИЗНЕС (требуется ур. 30)
     * ПЕРВЫЙ КЛАСС (требуется ур. 50)
   - Выбирает длительность: 5/10/15/20/30 минут

3. ИГРОВОЙ ПРОЦЕСС
   - Игрок управляет проводником (WASD/стрелки)
   - Перемещается по вагону с пассажирами
   - Таймер обратного отсчёта (визуальная индикация)
   - Шкалы: ЛОЯЛЬНОСТЬ и БЕЗОПАСНОСТЬ (70% стартовые)

4. ВЗАИМОДЕЙСТВИЕ С NPC
   - Подходит к пассажиру (дистанция < 100px)
   - Появляется подсказка [E] ГОВОРИТЬ / [E] ПОМОЧЬ
   - Нажимает E → открывается чат
   - Пишет сообщение или использует голосовой ввод
   - ИИ генерирует ответ с учётом архетипа пассажира
   - Шкалы обновляются в реальном времени

5. ПРИНЯТИЕ РЕШЕНИЙ
   Пример сценария:
   Ситуация: "Пассажир: Мне жарко, кондиционер не работает!"
   
   Наиболее вероятные варианты действий:
   A) "Проверю настройки климат-контроля" → +10 лояльность, +5 безопасность
   B) "Вызову технического специалиста" → +5 лояльность, +15 безопасность
   C) "Предложу пересадку в другой вагон" → +15 лояльность, 0 безопасность
   
   Каждое решение влияет на обе шкалы по-разному и ВСЕ решения обрабатываются ИИ-джижком и проверяются на
   адекватность, читерсвто(например использование вежливых слов много раз подряд для накручивания очков опыта)

6. ЗАВЕРШЕНИЕ ДИАЛОГА

   - Открывается экран РАЗБОРА ДИАЛОГА:
     * Анализ: "Анализ диалога и выявление ошибок/преимуществ, демонстрация альтернативных варинатов ответа в конкретной ситуации"
     * Рекомендации: "Личные рекомендации пользователю, направленные для улучшения навыков общения с пассажирами и решения нестандартных ситуаций"

7. ЗАВЕРШЕНИЕ СЕССИИ

   - Таймер истёк ИЛИ игрок нажал "ЗАВЕРШИТЬ"
   - Открывается экран РАЗБОРА СЕССИИ:
     * Итоговая лояльность: % за сессию (+ N за сессию)
     * Итоговая безопасность: % за сессию (+ N за сессию)
   - Начисление XP и обновление уровня
   - Разблокировка достижений (если есть)

7. ПРОСМОТР ПРОФИЛЯ
   - Данные пользователя
   - Список достижений
   - Прогресс до следующего уровня
   - Совет дня для улучшения навыков


ПЕРВЫЙ ПРИМЕР ИГРОВОГО СЦЕНАРИЯ:

Название: "Конфликт из-за места"
Класс: СТАНДАРТ
Сложность: Средняя

Контекст:
Пассажир А (Бизнес-турист) утверждает, что Пассажир Б (Студент) занял его место.
Оба пассажира требуют решения конфликта.

Возможные ветвления:
1. Проверить билеты обоих пассажиров
   → Выяснить, кто прав
   → Предложить компромисс (если оба правы)
   
2. Игнорировать конфликт
   → Лояльность: -20%
   → Безопасность: -10% (эскалация напряжённости)
   
3. Вызвать старшего проводника
   → Лояльность: -5% (задержка решения)
   → Безопасность: +10% (соблюдение протокола)

Идеальный исход:
- Проверить билеты → найти ошибку в системе бронирования
- Предложить Пассажиру Б бесплатное повышение класса
- Оба пассажира довольны: Лояльность +15%, Безопасность +10%

ВТОРОЙ ПРИМЕР ИГРОВОГО СЦЕНАРИЯ:

Название: "Пассажир спереди ведёт себя слишком громко"
Класс: СТАНДАРТ
Сложность: Средняя

Контекст:
Пассажир А (Старший) утверждает, что Пассажир Б (Семья) слишком громко себя ведут.
Пассажир А требует решения этой ситуации.

Возможные ветвления:
1. Попросить Пассажира Б вести себя потише.
   → Лояльность: -20%
   → Безопасность: -5% (Недовольствие требованиями персонала)
   
2. Игнорировать конфликт
   → Лояльность: -15%
   → Безопасность: -15% (Эскалация напряжённости)
   
3. Предложить сесть на свободное место
   → Лояльность: +5% 
   → Безопасность: +5% (Увеличение расстояния и избавление от излишнего шума)

Идеальный исход:
- Мягко попросить Пассажира Б быть чуть тише
- Предложить Пассажиру А беруши или наушники с шумоподавлением, а также бесплатный горячий напиток (чай/кофе) в качестве комплимента за неудобства
- Пассажир А доволен, а Пассажир Б не обижен: Лояльность +10%, Безопасность +10%

ТРЕТИЙ ПРИМЕР ИГРОВОГО СЦЕНАРИЯ:

Название: "Сломанный кондиционер"
Класс: СТАНДАРТ
Сложность: Легкая

Контекст:
Пассажир (Рабочий) жалуется на неработающий кондиционер и просит исправить поломку.

Возможные ветвления:
1. Предложить пассажиру охлаждающий напиток
   → Лояльность: -10%
   → Безопасность: -5% (Проблема не решена)
   
2. Вызвать специалиста
   → Лояльность: +5%
   → Безопасность: +10% (Починка неисправленной техники)
   
3. Предложить сесть на свободное место с работающим кондиционером
   → Лояльность: +10% 
   → Безопасность: -20% (Поломка может спровоцировать ЧС, подвергая риску жизни пассажиров)

Идеальный исход:
- Вызвать специалиста
- Попросить пассажира немного подождать, временно пересесть на другое место до исправления поломки
- Пассажир А доволен, риск чрезвычайной ситуации был сведен к нулю: Лояльность +10%, Безопасность +10%
